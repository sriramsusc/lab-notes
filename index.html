How this works

  1. You fill in a form. Each button above opens a short GitHub issue form.
  2. A bot checks it. Summaries and completion reports have to be substantial — thin ones get bounced back with a comment saying what to expand.
  3. It becomes a file. The bot commits a markdown file to _papers/ or _tasks/ with your metadata in the front matter, then closes the issue.
  4. The site rebuilds. This page updates within a minute or two.
